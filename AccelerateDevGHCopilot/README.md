# AccelerateDevGHCopilot Java (M3 Starter)

Java starter project for AZ-2007 Module 3: Develop Code Features.

## Focus

Students use GitHub Copilot to add book-search functionality to the console app domain.

## Prerequisites

- Java 21 (LTS)
- Maven 3.9+

## Build, test, and run

```bash
mvn clean test
mvn exec:java
```

## Data files

The console app reads and writes JSON files in `data/Json`.
